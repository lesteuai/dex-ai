A deterministic local job site

This site is a self-contained fixture for Dex AI rehearsals. It runs locally, uses no scripts and no remote assets, and always shows the same postings, filters and form fields.

Browse postings

How rehearsals use this fixture

  1. Search for postings and set filters.
  2. Open a posting and read its detail.
  3. Open the application form and fill its fields.
  4. Attempt to submit. The control plane blocks every submission.

No application is ever submitted from this fixture. Submission attempts are blocked by the rehearsal guard and recorded as blocked actions in the session history.
